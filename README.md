# Dockerization

Dockerization of several services

- **stack/** — AdGuard Home, Nginx Proxy Manager, Portainer, Pterodactyl (see `stack/README.md`)
- Wordpress with MySQL and PhPMyAdmin
- Minecraft vanilla server
- `homelab/` — Homepage + Pi-hole (conflicts with `stack/` ports)
- `bdd/` — Postgres/MariaDB dev databases
